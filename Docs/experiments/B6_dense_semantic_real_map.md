# B6 — плотная семантическая карта по реальным RGB-D и YOLOE

**Дата:** 2026-11-02. **Ветка:** `experiments/rtabmap-geometry-a0-20261031`.  
**Данные:** A6 TUM Freiburg1 desk full 595 RGB-D, 594 оптимизированные RTAB-Map-позы, B5 с YOLOE-26x на 119 keyframes.  
**Результат B6 local:** успешно воспроизведена визуализация из реальных артефактов; независимая проверка GitHub Actions [#41483699070](https://github.com/KiRiII-C/cv_vlm/actions/runs/41483699070).

## Мотивация

Старая карта [B5](B5_full_tracking_and_semantic_map.md) визуализировала 295147 семантически размеченных RGB-D точек, но на обзорном 3D-ракурсе облака отдельных категорий были малочитаемы. В дополнение требовалось отделить геометрию TSDF от семантических наблюдений и обеспечить понятный интерактивный интерфейс.

## Алгоритм и принятые определения

[Воспроизводимый B6 рендер](../../scripts/b6_render_dense_semantic_map.py) принимает исходные `b5_semantic_pointcloud.npz`, который содержит **295147 реальных 3D-точек из масок YOLOE**, и `A6/optimized_geometry/tsdf_cloud.ply` с **11624 измеренными TSDF-точками**. Входной класс — *предсказание* YOLOE, а не эталонная разметка.

Вокселизация по (v=0.012) м: каждой исходной точке приписывается целочисленный индекс (lfloor p/v floor); для каждой непустой ячейки сохраняются среднее положение действительно измеренных точек и счётчик реальной поддержки. Предсказанный класс определяется голосованием с весом исходной уверенности YOLOE. `purity` — доля взвешенных голосов победившего класса; конфликтные ячейки `purity<0.58` не окрашиваются в определённый класс на визуализации. **Не выполняется интерполяции, upsampling или генерации недостающих физических поверхностей**.

Формируются: `dense_semantic_map.png` (3D + 2 координатные проекции), `object_clouds_by_class.png` (раздельные категории), `interactive_dense_semantic_map.html` (WebGL с переключаемыми категориями), `semantic_voxels_measured.npz` (координаты + класс + support + purity), `semantic_voxels_colored.ply` (открывается в CloudCompare).

**Реальный локальный расчёт:** из 295147 точек получено **87282 непустых измеренных 3D-вокселя (1.2 см)**, без синтетических точек. Выделяются восемь категорий. Рендер показывает исходную TSDF-поверхность полупрозрачным фоном. Количество непустых вокселей не следует путать с исходной плотностью сенсора: физическое разрешение RGB-D не увеличилось.

## Ограничения

- Это семантическое облако **наблюдений**, а не 3D-облако отдельного физического экземпляра: один класс может содержать несколько одинаковых предметов и ошибки детектора.
- Нельзя считать распределение `purity` калиброванной вероятностью достоверности, поскольку один и тот же объект мог попасть во множество кадров, а ошибки YOLOE коррелируют.
- Без оценки GT физических объектов на TUM нельзя утверждать, что окрашивание даёт правильную физическую идентичность.
- Реальные поверхности могут оставаться разреженными в местах без наблюдаемой глубины; художественное заполнение было бы подделкой измерения.
- Карта не прошла проверку безопасности навигации и не считается `nav_ready`.

## Продолжение по проекту

Результаты B6 визуализируют реальные наблюдения, а не исправляют низкий IDF1 B5. Для долговременного `object_uuid` использовать существующую [ObjectMemoryV2](../../src/semantic_map/object_memory_v2.py) и консервативные критерии C0/C1. Неподтверждённые экземпляры должны оставаться гипотезами.
