## Прогностические свойства OdomInfo

В таблице ROC AUC характеризует предсказание **ошибочных поз на этой конкретной последовательности** по *необученному* направленному диагностическому признаку. Нельзя использовать его как доказательство универсальной достоверности /odom.

| OdomInfo-признак | AUC для ATE > 10 см (28 событий) | AUC для RPE translation > 2.5 см (8 событий) |
|---|---:|---:|
| Меньше inliers | 0.655 | 0.847 |
| Меньше matches | 0.374 | 0.849 |
| **Меньше inliers/matches** | **0.813** | 0.796 |
| Больше covariance (sqrt max) | 0.583 | **0.842** |
| Больше время оценки движения | 0.678 | 0.650 |
| Меньше features | 0.723 | 0.667 |
| RTAB-Map `lost` | **не определена** | **не определена** |

- AUC `inliers/matches` для крупной ATE: исследовательский блочный bootstrap 95% **[0.683, 0.925]**, блок 30 кадров, 202 допустимых повторения из 300. Это не доверительный интервал переносимости на другие сцены.
- **Все 28 крупных ATE оказались в начальных 50 кадрах**, поэтому AUC существенно зависит от временного сегмента и глобального SE(3)-согласования. Это сильный конфаундинг, не позволяющий заявлять независимую предсказательную способность.
- Нижний квинтиль `inliers/matches` (порог ≈0.56831; 119 кадров на проверку) захватил **18/28** крупной ATE (recall 64.3%), пропустил **10/28**. Простой порог неприемлем как фильтр безопасности.
- В верхних 20% по числу `inliers` (`>=350`) были **2 кадра с ATE >10 см**. Сильная локальная регистрация может сосуществовать с большой глобальной ошибкой.
- Для локальной RPE и covariance: Spearman(увеличение sigma, увеличение RPE translation) ≈ **+0.496**, а для ATE ≈ **−0.286**. Это согласуется с локальным характером ковариации, но не доказывает её вероятностную калибровку.
- Для RPE rotation >3° отсутствуют положительные события, поэтому AUC **не определена**, а не 1.0.
- Только 8 событий крупной RPE translation: оценка AUC статистически ненадёжна, несмотря на кажущиеся высокими значения.

## Итоговые ограничения и решение

1. `lost=false` — только внутренняя успешность регистрации, **не гарантирует** глобальную метрическую точность.
2. `inliers`, `matches`, их доля и covariance **не являются заменой глобального доверия к позе**; их полезность должна оцениваться раздельно для локальной регистрации и глобального графа.
3. Не вводить жёсткую отбраковку или коррекцию поз по найденным на одном наборе порогам, это создаёт риск пропущенных ошибок и повышает selection bias.
4. Для обобщения необходимы независимые **полные** реальные последовательности с различными движениями (TUM Freiburg1 room, Freiburg3 long_office_household), проверка loop-closure outliers и relocalization после рестарта.
5. Высокая ATE может быть результатом накопленного дрейфа. Предпочесть гибрид: RTAB-Map OdomInfo для локального качества + согласованность pose graph / loop closures для глобальной локализации + depth-based obstacle safety независимо от семантики.

**Результат A5:** анализ завершён; потенциально полезные диагностические признаки выявлены, но требуемая уверенность в глобальной позе по одной лишь OdomInfo не достигается.
