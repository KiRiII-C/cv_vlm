# A5 — насколько диагностика RTAB-Map предсказывает реальную ошибку позы?

**Дата:** 2026-11-02.  
**Ветка:** `experiments/rtabmap-geometry-a0-20261031`.  
**Статус:** FULL_DATASET_PASS / GENERALIZATION_NOT_VALIDATED. Численные результаты: [A5_results.md](A5_results.md).  
**CI:** [GitHub Actions run 41442937993](https://github.com/KiRiII-C/cv_vlm/actions/runs/41442937993).

## Исследовательская задача

Проверить, насколько собственные диагностические показатели `rtabmap_msgs/OdomInfo` действительно позволяют судить о метрической точности визуальной одометрии. В A4 использованы все 595 однозначно сопоставленных RGB-D наблюдений TUM Freiburg1 desk, подтверждённых через `OdomInfoLite`. На полном наборе `lost=false` во всех 595 случаях: этот бинарный флаг не пригоден для ранжирования качества поз в этой последовательности. Однако количество inliers меняется от 0 до 487, а `matches` — от 0 до 609.

**Гипотезы:** (H1) меньше inliers / matches и меньшая доля `inliers/matches` связаны с большей локальной ошибкой движения; (H2) ковариация /odom отражает в первую очередь локальную неопределённость измерения и не равна глобальной погрешности накопленной траектории; (H3) возможны кадры с высоким inliers и большой абсолютной ATE из-за накопленного дрейфа.

## Данные и гарантии

- Для нового экспериментального запуска используется **вся последовательность**, включая все 595 уникальных RGB-D-пар, без ограничения по числу кадров или пропусков по шагу. Используются все строки исходных `rgb.txt` и `depth.txt`, сопоставленные без повторного использования Depth.
- Пакеты подаются через `rtabmap_msgs/RGBDImage` с подтверждением обработки `OdomInfoLite` каждого кадра. Потеря любого кадра — ошибка покрытия.
- Ground truth `TUM groundtruth.txt` загружается **только после завершения SLAM**, чтобы посчитать ошибки. Он не используется для формирования кадров, позиционирования, построения карты или принятия решения о качестве регистрации.
- Формируются сохранённые `full_sequence.publish.json`, `full_sequence.odom.json` и `full_sequence.odominfo.json`, а далее `per_frame_pose_error.csv`.

## Методы

1. Для всех имеющих GT и численно допустимую одометрию кадров выполняется **одно** SE(3)-согласование рассчитанной траектории с GT без масштабирования. По его результатам вычисляется ATE каждой позы.
2. Для каждой пары **соседних в исходной полной последовательности** кадров независимо вычисляется локальная RPE: трансляционная ошибка в метрах и ошибка поворота в градусах. Нельзя «склеивать» разрывы путём сравнения далёких друг от друга кадров.
3. На всех соответствующих кадрах вычисляются Spearman (ранговая корреляция) и ROC AUC для ранжирования ошибок по неизменённым диагностическим величинам: отрицательные inliers, matches, inlier ratio, число features; положительные `sqrt(max(cov_xyz))` и время регистрации. Это не обученные классификаторы, а фиксированные одномерные показатели.
4. До эксперимента установлены пороги: крупная **ATE > 0.10 м**, крупная локальная трансляционная **RPE > 0.025 м**, крупная угловая **RPE > 3°**. Изменять пороги на основании результата для «улучшения AUC» запрещено.
5. Для AUC, когда классы присутствуют, оценивается исследовательский 95% интервал методом **временного блочного bootstrap** (длина блока 30 кадров, 300 ресэмплингов). Это не обеспечивает строгой независимости наблюдений и не заменяет проверку на других датасетах.
6. Фиксируются 15 худших кадров по ATE, доля крупных ошибок с inliers выше 80-го перцентиля и распределение ошибки по классам. При постоянной `lost=false` AUC маркируется `null` как **неопределённая**, не 0.5.
7. Ковариация визуальной одометрии НЕ считается автоматически корректной вероятностной оценкой глобального положения. Проверяется её ассоциация с ошибками, без автоматического признания калиброванности.

## Приёмочные критерии

- 595 подтверждённых исходных RGB-D-пар, отсутствие кадрового прореживания.
- Отчёт `results/a5/odometry_predictive_report.json`, полный `results/a5/per_frame_pose_error.csv`, логи A4/A5 и база RTAB-Map сохранены в Actions.
- Вычисление ATE, RPE и численности всех категорий сопровождается проверкой совпадения временных меток и исключением кадра инициализации с искусственно большой ковариацией из метрических сравнений.
- Отрицательный или неоднозначный результат сохраняется без подбора порогов post hoc.
- **Эксперимент завершён, результаты подтверждены по реальным JSON и CSV. Переносимость результатов на другие сцены и готовность к навигации не доказаны.**
