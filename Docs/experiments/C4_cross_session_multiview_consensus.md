## Исходная проблема

Этап C3 обработал полную независимую TUM desk2: 639 кадров глубины, из которых лишь 25 имеют принятую сохранённую A8 локализацию в карте desk. На этих 25 кадрах модель дала 69 валидных YOLOE-26x 3D-наблюдений; 63 получили геометрическую кандидатную связь с одним из 15 C1 UUID, по крайней мере 13 C1 гипотез встречены вновь. Однако это **покадровые геометрические кандидаты, не физические идентичности**. Нужно проверить согласованность нескольких ракурсов, запретить ошибочную переинтерпретацию пропуска и выявлять противоречия с независимой глубиной C2.

## Протокол

- Читаются **только** уже полученные оригинальные C2 JSON/JSONL и C3 JSON/JSONL. Никаких синтетических кадро-измерений, GT-ID или переобучения.
- Для каждого match проверяется реальная ранее принятая глобальная поза, соответствующий UUID и глубинное evidence из C2. Если нет позы или источника, эксперимент падает с ошибкой.
- В одном независимом кадре допустимо не более одной сегментации на UUID. Нельзя обойти one-to-one, создать новый persistent ID или заменить старый.
- Для каждого UUID учитываются разные физические ракурсы: расстояние между позициями камеры \\(\\ge 0.12\\) м **или** угол вращения \\(\\ge 15^\\circ\\). Проверка делается между принятыми ракурсами; несколько почти одинаковых YOLOE обнаружений не считаются независимым доказательством.
- Фиксируются число новых наблюдений, геометрическая оценка C3, отклонение центра 3D-облака между кадрами и подтверждённая/противоречащая глубина C2 по *тем же кадрам*. Эти оценки не являются ground-truth идентичности.
- Статус `MULTIVIEW_GEOMETRY_SUPPORTED_NOT_PHYSICAL_ID` возможен лишь при трёх независимых ракурсах, хотя бы двух совпадающих depth-проверках, медиане score \\(\\ge 0.60\\) и медианном отклонении центров \\(\\le 0.30\\) м. Пороговые значения — заранее заданные инженерные правила, не калиброванная вероятность.
- Любое обнаруженное противоречие с C2 требует `REVIEW` даже при высоком геометрическом score. Отсутствие YOLOE-маски = `UNKNOWN_NOT_ABSENT`, не исчезновение объекта.
- Валидатор проверяет полные 15 UUID × 25 принятых поз и баланс всех 69 C3 наблюдений. Никакие результаты не имитируются.

## Что можно установить

Из фактических свидетельств C2 и C3 можно получить интерпретируемый список устойчивых **геометрических** гипотез, явные причины откладывания решения и список мест для повторного активного наблюдения. При повторном использовании одного класса нельзя автоматически различить две физически похожие вещи. Точность IDF1 неизвестна: в этих TUM записях нет общего независимого physical instance GT.

## Ограничения и следующий контроль

Требуется отдельный test с физически размеченными передвижениями (moved/stationary/occluded/absent), извлечением реальных визуальных эмбеддингов из обеих сессий, глобальной релокализацией без GT-подсказок и adversarial конфликтами одинакового класса. Until then: no automatic C1 database mutation, no physical-ID PASS, no moved/deleted assertions. Robot safety remains on live depth mapping, independently of semantic classification.

Автоматически проверенная таблица результатов публикуется только после успешного GitHub Actions в [C4_actual_results.md](C4_actual_results.md); ссылка может отсутствовать до подтверждения CI.
