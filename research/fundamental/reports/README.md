# Журнал фундаментальных экспериментов

Этот каталог является **постоянным журналом** исследований в ветке `experiments/fundamental-spatial-representations-20261102`. Отчёты здесь сохраняются непосредственно после выполнения GitHub Actions, а не заменяются общими описаниями проекта.

## Правила ведения

1. Каждый эксперимент получает ID `EXP-YYYYMMDD-NN`, ссылку на исходный код, датасет, точную версию workflow/commit SHA и ссылку на GitHub Actions.
2. Обязательно фиксируются уравнения/физическая модель, независимые и зависимые переменные, train/validation/test, baselines, критерии отказа, ошибки и отрицательные результаты.
3. **Необработанные логи и результаты** сохраняются как GitHub Actions artifacts; в отчётах публикуются проверенные числа и ссылки.
4. Число «проверенных гипотез» не подменяется количеством комбинаций параметров. Реальное датасетное воспроизведение не приравнивается к доказанной новизне.
5. В случае ошибки калибровки или метрики первоначальный результат помечается `INVALIDATED`, новый результат публикуется отдельным revision.
6. Результаты на реальных кадрах не приравниваются к объектному Re-ID, SLAM или навигации без соответствующей GT-разметки.

**[Итоговый отчёт 2026-11-02](2026-11-02-summary.md)** — основные результаты, отрицательные проверки, обновление научной гипотезы и следующие критерии фальсификации.

## Текущие ограничения

Эксперименты на публичных TUM/Bonn используют реальные RGB-D-последовательности и внешние ground-truth позы. Они пока не обеспечивают истинных ID подвижных объектов, не проверяют безопасную навигацию и не доказывают работоспособность на автономной платформе.
