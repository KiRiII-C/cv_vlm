# EXP-20261102-01 — Многовидовая геометрическая память и достоверность наблюдений

**Статус:** `EXECUTED_ON_REAL_RGBD; ANALYZED`  
**Код:** [multiview_evidence.py](../multiview_evidence.py)  
**Среды:** реальные измерения TUM RGB-D fr1/xyz; Bonn moving_obstructing_box.  
**Версия входных данных:** исходные публичные последовательности, скачиваемые workflow в каждом запуске.

## Исследовательский вопрос

Можно ли повысить достоверность краткосрочной пространственной памяти без обучения нового энкодера, если хранить *согласованность физических свидетельств* из разных ракурсов, а не только изображение или одно реконструированное значение глубины?

Это не утверждение о новой математике; изучается, можно ли в дальнейшем строить task-sufficient representation из распределения свидетельств.

## Математическая модель

Из пикселя `(u,v)` и измеренной глубины `d` восстановить точку:
```math
p_w=T_{wc}\,dK^{-1}[u,v,1]^T.
```
Затем перенести её в координаты другого наблюдения:
```math
p_t=T_{wc,t}^{-1}p_w
```
и построить минимальную по дальности поверхность по лучу (z-buffer).

Для каждого целевого пикселя получаем множество **предсказанных** глубин из прошлого:
`D_{t,u}={d^(j)_{t,u}}`.
Доступные операторы: последний кадр; минимальная глубина; медиана; усреднение внутри медианного робастного окна; медиана с отказом при недостатке свидетельств; строгий отказ при большом MAD.

Условный отказ: `n_obs≥2, MAD<0.06m` и `n_obs≥3, MAD<0.035m`. Порог задан до получения результатов.

## Проверяемые гипотезы

H1: по сравнению с памятью одного кадра многовидовая память увеличит **coverage**, но не обязательно снизит ошибку глубины на общей области.  
H2: отказ на основании числа наблюдений и межвидового MAD снизит долю больших ошибок среди принятых предсказаний, но уменьшит coverage.  
H3: на динамическом Bonn риск конфликтующих наблюдений будет больше, чем на статическом TUM, при условии сопоставимых поз/калибровки.

## Дизайн

- 100 выбранных кадров из исходной записи, целевые кадры 16,18,...,98.
- Используются только прошлые 1,2,3,4,6,8 кадров для каждого целевого кадра.
- Целевую глубину **не использовать** при формировании прогноза; она открывается только для метрик.
- Позы TUM: опубликованные GT; позы Bonn: опубликованные GT с отдельно проверенной внешней калибровкой.
- Оцениваются покрытие пикселей, MAE по измеренной глубине, доля ошибок более 10 см, вероятность видимого конфликта.
- Для честного сравнения методов MAE считается дополнительно на одинаковой области перекрытия.
- 95%-й доверительный интервал: bootstrap с пересэмплированием *кадров*, а не пикселей.
- Нельзя трактовать отличие глубины как доказанное перемещение объекта: возможны шум, окклюзия, калибровка и изменение видимой поверхности.

## Критерии фальсификации

H1 опровергается, если покрытие не растёт; H2 опровергается, если риск больших ошибок не уменьшается при заданном условии отказа; H3 может остаться неопределённой из-за различий двух последовательностей.

### Честное попиксельное сопоставление

На общей области последних и медианных предсказаний, без преимущества дополнительного покрытия, TUM: `recent=0.02179 м`, `median=0.02671 м` (481 730 пикселей, 42 кадра). Bonn: `recent=0.07267 м`, `median=0.14010 м` (625 141 пиксель, 42 кадра).

### Статус гипотез

- **H1 — частично подтверждена:** шесть ракурсов существенно увеличили покрытие, но ухудшили точность даже на общей области.
- **H2 — подтверждена только относительно простого multi-view median:** отбраковка согласованности уменьшает ошибки; относительно baseline последнего кадра улучшения не показано.
- **H3 — остаётся неопределённой:** у Bonn больше ошибок геометрического согласования, но сравниваются разные сцены, траектории и датчики; не вся ошибка вызвана динамикой.

**Ключевой отрицательный вывод:** простая временная фузия без модели изменения сцены может делать память хуже. Следующая гипотеза — память с явным временем актуальности и условным обновлением достоверности. Это новое исследовательское предложение, а не доказанная новизна алгоритма.

### Воспроизводимость и неопределённости

95%-й CI вычислялся bootstrap по целевым кадрам (400 повторений). Кадры последовательности всё ещё зависимы; эти интервалы **не** отражают неопределённость по независимым помещениям. Кроме того, эталонные позы являются внешним GT, так что данные числа не измеряют влияние реального RTAB-Map.
