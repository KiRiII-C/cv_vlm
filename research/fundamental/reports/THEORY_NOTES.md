# Математический журнал: гипотезы следующего уровня

*Дата: 2026-11-02. Статус: идеи для фальсифицируемых исследований, не доказанная научная новизна.*

## Вывод из EXP-20261102-01

Обычное накопление прошлого RGB-D: *coverage растёт, но риск геометрической ошибки может расти ещё быстрее*. В обработанных реальных датасетах медианная многовидовая память не превзошла последнего наблюдения по точности, особенно Bonn. Поэтому ключевым объектом оптимизации должна быть не детализация карты, а **ожидаемый риск использования конкретного элемента памяти при следующем действии**.

Определим память по каждому пространственному участку как тройку

\[
M_t(x)=\bigl(q_t(x),\,P_t(x),\,E_t(x)\bigr),
\]

где \(q_t\) — оценка физического состояния, \(P_t\) — неоднозначность/доверие, \(E_t\) — независимые свидетельства: история лучей видимости, положение камеры, время и остатки прогноза.

**Предлагаемый оператор (не проверен):**

\[
\tilde w_j(x,t)=\underbrace{p(\mathrm{vis}_j\mid x)}_{\text{наблюдаемость}}\,
\underbrace{e^{-\Delta t_j/\tau_x}}_{\text{старение}}\,
\underbrace{e^{-r_j(x)^2/(2\sigma_j^2)}}_{\text{робастное согласие}}.
\]

\[
q_t(x)=\arg\min_q\sum_j\tilde w_j \rho_{\sigma_j}(q-z_j),
\quad
P_t(x)\approx\big(\sum_j\tilde w_j/\sigma_j^2\big)^{-1}.
\]

Существование \(\tau_x\) не должно подразумевать, что объект обязательно стареет со временем: параметры модели должны отличать реальные движения от информационного устаревания. В коррелированных кадрах нельзя суммировать уверенность как независимые измерения; следует вводить эффективное число наблюдений и учитывать общую ошибку позы.

Для action-conditioned query выбираем действие \(a\) только при

\[
\Pr\{L_{\mathrm{safety}}(a,S_t)>\ell_{\max}\mid M_t\}<\epsilon.
\]

Такой риск нельзя вычислять только из визуальных embeddings: требуется независимый контур актуальных препятствий.

## Вывод из EXP-20261102-02

В задаче физически различимых, но RGB-похожих точек DCT и локальная текстура оказались полезнее грубых RGB и 3D-статистик. Это **не** доказывает, что текстура лучше 3D для других задач. Следует условно выбирать/обучать представление по информации, которую нужно сохранить:

\[
Z=f_\theta(o,\mathcal T), \quad
\min I(Z;O)+\beta\,\mathbb E[\mathcal L_{\mathcal T}(Z,S)]
\]

где \(\mathcal T\) — класс запросов: локальное соответствие, повторная локализация, ID экземпляра, форма, пространственные отношения, навигационная безопасность. Декодеры для задач и конкурирующие baseline должны измеряться отдельно.

## Гипотеза о наблюдаемости вместо принудительного ID

Если две перестановки физических объектов дают одинаковый закон будущих допустимых RGB-D-наблюдений при любых допустимых действиях, исторические идентификаторы нельзя восстановить из измерений. Вместо ложной уверенности хранить распределение на классах наблюдательно эквивалентных состояний:

\[
[s]_{\mathcal A} =
\{s':P(o_{t+1:t+H}\mid s,\mathbf a)=P(o_{t+1:t+H}\mid s',\mathbf a)
\;\forall \mathbf a\in\mathcal A^H\}.
\]

Математическая идея observable quotient **уже опубликована** (Jiao et al., *Knowledge-Based Systems*, 2026, DOI 10.1016/j.knosys.2026.116768); здесь исследуется только специфический RGB-D случай с изменяющейся геометрией, ограниченной памятью, частичной видимостью и требованием безопасности.

## Обязательные контрэксперименты

1. Не использовать Bonn и TUM для выбора порогов, а затем объявлять те же данные независимым тестом.
2. Проверить сохранение результатов на третьей комнате и на GT-instance наборе.
3. Отдельно варьировать движение камеры, реальное движение объектов, перекрытие и ошибки позы.
4. Сравнивать при одинаковом бюджете памяти и сопоставимой вычислительной задержке.
5. Заранее фиксировать модель отрицательных примеров — RGB-hard, geometry-hard и unbiased — иначе сравнение модальностей может быть некорректно.
6. Сравнивать с существующими spatial belief/world-model проектами, а не объявлять известные принципы новыми.
