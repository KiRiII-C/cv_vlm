# EXP-20261102-02 — Пространственная идентифицируемость локальных признаков

**Статус:** `IMPLEMENTED; RUN NOT YET VERIFIED`  
**Код:** [hard_negative_retrieval.py](../hard_negative_retrieval.py).  
**Датасеты:** реальные TUM RGB-D fr1/xyz и Bonn RGB-D moving_obstructing_box.

## Гипотеза

Известный результат случайно выбранных отрицательных примеров может существенно завышать качество локального дескриптора. Для пространственного восприятия особенно важна способность отличать *визуально похожие, но физически различные 3D-участки*.

H1: спектральный дескриптор межточечных расстояний может оказаться устойчивее визуального при RGB-похожих отвлекающих участках.  
H2: объединение цвета и геометрии может дать прирост, но может проиграть отдельному дескриптору из-за некалиброванного масштаба признаков.

## Метод

1. Получить **истинную пару физической 3D-области** через GT-позу камеры и совпадение измеренной глубины (погрешность не более 7 см).
2. Найти четыре разных измеренных участка в соседней области следующего изображения на физическом расстоянии не менее 12 см от истинной точки.
3. Из них выбрать четыре визуально наиболее похожих на исходную область, измеряя расстояние RGB-дескриптора.
4. Выполнить 5-way retrieval для шести альтернатив: цветовая статистика, DCT, геометрические моменты глубины, спектр расстояний 3D-точек, абсолютные координаты, слияние цвета и геометрии.
5. Отчёт: Recall@1, margin, 95% CI по ресэмплингу *пар кадров*, число реальных проверочных наблюдений.

## Риски интерпретации

- Hard negatives целенаправленно выбираются по RGB, что смещает результат против метода RGB. Поэтому сравнение справедливо для определённой задачи RGB-неразличимости, а не для произвольных областей.
- Физически отличная точка может принадлежать тому же объекту и не требует другого instance ID.
- Использование одной траектории не обеспечивает независимой оценки генерализации на другие помещения.
- Эталонные позы используются для формирования GT, а не выдаются за результат SLAM.
- Высокий Recall@1 не доказывает возможность восстановить экземпляр после длительного исчезновения.

## Критерий остановки

Если в какой-либо записи менее 80 проверяемых соответствий, тест должен завершаться ошибкой. Неточное сопоставление запрещено заменять выдуманной меткой.
