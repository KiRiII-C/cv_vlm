# EXP-20261102-04 — Углублённое обучение нейросетевых представлений RGB-D и трансформеров

**Статус:** EXECUTED / 12 из 12 GitHub Actions SUCCESS. [Полные результаты и веса](EXP-20261102-04-results.md).  
**Код:** [strong_encoder_training.py](../strong_encoder_training.py)  
**Данные:** оригинальные TUM RGB-D fr1/xyz и Bonn RGB-D moving_obstructing_box, без синтетических изображений.

## Причина эксперимента

Ранее пять небольших моделей обучались по 8 эпох на одной RGB-D-последовательности. Простая цель «различить случайно взятую чужую точку» приводила к высокому Recall@1, но более строгий тест с четырьмя похожими по RGB областями обнаружил сильное ухудшение. Нельзя заключать о роли attention по таким недообученным моделям.

## Дизайн

- **48 эпох** каждому кандидату на CPU GitHub Actions; AdamW, cosine annealing, clipping и легкая фотометрическая аугментация.
- **Два независимых seed**, одинаковые исходные train/validation/test и objective.
- Обучение только на первых 58 RGB-D-кадрах TUM, позитивные пары получены через опубликованные GT-позы и подтверждённую глубину.
- Положительные пары + симметричная in-batch InfoNCE с температурой 0.12.
- Дополнительно обучение выбору одного физически правильного наблюдения из пяти RGB-похожих кандидатов (hard-negative cross entropy, коэффициент 0.7). Неверные области берутся из **реальных** RGB-D-кадров.
- **Валидация только TUM (кадры 64–78)**, лучший checkpoint выбирается по validation Recall@1.
- **Слепые тесты**: TUM кадры 82–99 и Bonn (другая комната и камера) без какой-либо оптимизации на Bonn.
- На тестах 5-way Recall@1 и bootstrap CI, ресэмплирование по парам кадров. Хранятся все 48 значений training loss и validation Recall@1; best.pt и metrics.json выгружаются как артефакты CI.

## Архитектуры

| Код | Индуктивный принцип |
|---|---|
| mlp_plus | плотные нелинейные преобразования RGB-D патча, без convolution/attention |
| rgbd_cnn_plus | трёхслойные пространственные свёртки |
| vit_2layer | RGB-D patch tokens 3×3, learnable CLS, 2 слоя self-attention, width 96 |
| vit_4layer | RGB-D patch tokens 3×3, learnable CLS, 4 слоя self-attention, width 128 |
| geometry_vit | tokens на depth+XYZ, 2 слоя Transformer |
| conv_transformer | CNN-стем + 2 слоя Transformer |

## Проверяемые гипотезы

H1: усиленное обучение и работа со сложными отрицательными примерами обеспечивают более устойчивые cross-scene признаки, чем прежний упрощённый objective.

H2: более ёмкий Transformer выигрывает у мелкого при корректной валидации. Возможный отрицательный результат: из-за малого train-сета рост ёмкости увеличит overfitting.

H3: геометрически ориентированные токены обеспечат лучшую переносимость между датчиками, чем RGB-D tokens. Возможный отрицательный результат: при смещении распределений глубины геометрические признаки столь же нестабильны.

**Контроли и ограничения:** архитектуры не match по параметрам/FLOPs, аугментации не моделируют реальный разрыв между датчиками, TUM — одна траектория и одна комната. Более длинное обучение не гарантирует улучшения. Кроме того, in-batch negatives могут содержать ненамеренные false negatives из близлежащих областей той же поверхности. Настоящее сравнение pretrained DINOv3/VGGT/больших RGB-D 3D энкодеров здесь не выполнено.

## Что запрещено заключать

- «Сильный Transformer лучше MLP», пока нет независимых данных и доверительных интервалов.
- «Объектная память улучшилась», поскольку измеряется локальный 3D correspondence retrieval, а не GT ID объектов.
- «Это новый фундаментальный метод» — данные проверяют известные архитектурные принципы.
