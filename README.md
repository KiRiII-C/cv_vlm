# cv_vlm

Прототип офлайн-пайплайна семантической навигации в духе OpenMask3D для датасета TUM RGB-D.

## Возможности
- Чтение кадров TUM RGB-D с учётом поз камеры.
- Лёгкая генерация масок по глубине (замена тяжёлых моделей на эвристику; можно подставить свою сегментацию).
- Проекция масок в 3D, агрегация в объекты и кластеризация по близости.
- CLI для построения карты, поиска объектов по классу и вычисления простой точки подхода.

## Установка
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Использование
1. Скачайте последовательность TUM RGB-D (директория должна содержать `rgb.txt`, `depth.txt`, `groundtruth.txt`).
2. Постройте карту (параметры камеры можно уточнить в README TUM):
```bash
cv-vlm build-map /path/to/tum/sequence ./output_map \
  --fx 525 --fy 525 --cx 319.5 --cy 239.5 \
  --default-class "object" --merge-distance 0.6 --max-points-per-mask 8000
```
3. Найдите объекты интересующего класса (подстрочный поиск):
```bash
cv-vlm query ./output_map chair
```
4. Получите точку подхода к конкретному объекту:
```bash
cv-vlm goto ./output_map 0 --offset 0.8
```

## Как это работает
- `DepthMaskGenerator` выделяет ближние по глубине области и разбивает их на компоненты связности — удобно для быстрого прототипа на GPU 8 GB.
- `OfflineMapBuilder` проецирует точки масок в мир по позе камеры, сэмплирует их и сливает в `ObjectStore` с кластеризацией по центроидам.
- `ObjectStore` сохраняет метаданные в `objects.json`, которые можно быстро запрашивать по классу.
- `compute_goal` оценивает точку остановки на прямой «мировой ноль → объект» с указанным отступом.

## Подмена сегментации
`DepthMaskGenerator` — лишь заглушка. Можно внедрить свою модель, вернув список `MaskRegion` c булевыми масками и именами классов, и передать её в `OfflineMapBuilder` по аналогии.
